# Sistema de Gestión de Biblioteca
## Descripción
Este proyecto consiste en una aplicación de consola desarrollada en Python para gestionar una biblioteca. Permite administrar libros y socios, realizar préstamos y devoluciones, y consultar la información almacenada.

## Funcionalidades
El programa ofrece las siguientes opciones:

- Mostrar libros: Muestra todos los libros registrados en la biblioteca.
- Mostrar libros disponibles: Muestra únicamente los libros que están disponibles para préstamo.
- Buscar libro: Permite buscar un libro por su título.
- Prestar libro: Permite realizar el préstamo de un libro a un socio utilizando sus respectivos códigos.
- Devolver libro: Permite devolver un libro prestado por un socio.
- Mostrar préstamos: Muestra los préstamos registrados actualmente.
- Añadir libro o socio: Permite registrar nuevos libros y socios en la biblioteca.
